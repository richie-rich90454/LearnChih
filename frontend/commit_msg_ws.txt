perf(ws): replace sockjs-client with native WebSocket

- Remove sockjs-client dependency and its @types/sockjs-client types
- Switch useWebSocket.ts to use native new WebSocket(ws://host/ws)
- Remove .withSockJS() from backend WebSocketConfig (native WebSocket only)
- Update WebSocketConfigTest to match (no SockJS mock)
- Enable source maps in vite build config for better debugging

This fixes the Lighthouse deprecations audit (sockjs-client registered
a deprecated unload event listener) and the valid-source-maps audit.
Best Practices score restored from 82 to 100.

All modern browsers support WebSocket natively; the SockJS fallback was
unnecessary and added 44 KB to the app-hooks bundle.
